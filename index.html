Introduction

The Green Together system

One source of truth for the brand in code. Everything on this page is read live from code-tokens.css — no hand-copied values, so it can't drift.

The approved shelf — what ships in code. v1.1.0, last promoted from Figma on 20 Sep 2026. Figma is the studio and holds everything; this page holds only what has been promoted: decided, named and accessible. Everything here is read live from code-tokens.css, so it can't drift from the package.

Not here yet: components (Figma only) · the full spacing / radius / shadow scales · dark mode. Each is a promotion waiting to happen — see VERSION.md for what's open.

The primary action colour is surface-scoped — flip the toggle and watch --color-primary change.

Install

npm i "@greentogether/design-system": "github:GreenTogetherApp/green-together-design-system#v1.1.0"

/* app root */  @import '@greentogether/design-system/code-tokens.css';
/* tailwind   */ presets: [require('@greentogether/design-system/tailwind')]

Surfaces

One app, two lenses — not two apps. Surface A (employee) = green primary. Surface B (admin) = dark-blue primary; green reserved for savings/positive. Set data-surface="a|b" on the root.

Colors

Grouped by role. Each swatch shows the live hex and whether white / ink text passes WCAG AA on it.

Promoted sets

Promoted from the Figma studio on 20 Sep 2026. Figma name → CSS var: text/primary → --text-primary. Where a promoted value disagrees with an older shelf token, both ship until the decision is made — the open ones are listed in VERSION.md.

Accessibility

Colour decisions are checked against WCAG AA (4.5:1 text, 3:1 UI). The AA/AAA chips on every swatch above are computed live from the token value — so an inaccessible pairing is visible on sight, not discovered later.
